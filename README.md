# QuickNotes API Project

QuickNotes is a note-taking application that demonstrates how a frontend application communicates with an API. The project uses JavaScript to perform GET, POST and DELETE requests while also documenting the backend API design, database structure and scalable architecture needed for a real-world service.

---

# Features

- Load notes from an API using GET requests
- Create new notes using POST requests
- Delete notes using DELETE requests
- Form validation for note creation
- Dynamic rendering of notes
- REST API design documentation
- Database design documentation
- Scalable system architecture planning

---

# Running the Project Locally

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder.

3. Open `index.html` using Live Server in VS Code.

The application will run in your browser.
